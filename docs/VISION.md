# Beacon Vision

Ein SaaS-Tool, das Agenturen und Webentwicklern zeigt, wie gut die Websites
ihrer Kunden für KI-Agenten vorbereitet sind — und ihnen hilft, diese zu optimieren.

**"Lighthouse für Agentic Web Readiness."**

## Readiness-Level-Modell

| Level | Name | Beschreibung |
|---|---|---|
| 0 | Unsichtbar | KI kann die Website nicht sinnvoll verarbeiten |
| 1 | Lesbar | KI kann Inhalte lesen und zitieren |
| 2 | Interaktiv | KI-Agent kann mit der Website interagieren |
| 3 | Transaktional | KI-Agent kann Transaktionen durchführen |

## Differenzierung

- Analyse + automatische Fix-Generierung (nicht nur Monitoring)
- Level 0-3 inkl. Agentic Interaction (nicht nur GEO/AEO)
- White-Label Reports für Agenturen
- DACH-Fokus, deutschsprachig

## Zielgruppe MVP: Agenturen (DACH)

~15.000-20.000 Web-/SEO-Agenturen. Multiplikator: 1 Agentur = 10-50 Endkunden.
